# Agent instructions · Financial Visualization

Read `skills/financial-visualization/SKILL.md` before starting any financial report visualization.

Treat primary disclosures and exact reporting periods as authoritative; never infer missing figures from aesthetics or labels. Distinguish reported, calculated, illustrative, estimated and unverified. No market-data price, timestamp, valuation multiple or forecast may be claimed as current without dated source verification.

Maintain a source locator for every factual number, check numerical reconciliation, and use the chart catalog to decide which visual answers the reader's question. Always preserve a plain HTML table for important quantities. Prefer SVG rendering; complex layouts may use Canvas when warranted, with independent export.

Run the financial validator, automated tests, and real browser QA before claiming success. Never claim CI passed, PR merged, or Pages deployed without checking remote status. Never import copyrighted graphics, templates, fonts or code from the inspiration project without verified permissions.
